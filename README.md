我希望可以有一个工具管理我在不同社交平台的帖子。手动复制粘贴是一件很累的事情，更别说有些社交平台有独特的功能或者需要不一样的文案。

要求：

1. 使用go和vue编写一个webui程序。
2. 可以关联许多社交平台，这里的要求是Fediverse和Bluesky使用官方API/SDK，X(推特)、微博、小红书可以使用油猴脚本在页面上建立通讯，或者其他更好的方法。
3. 一个社交平台允许多个账号。允许多个profile管理不同的内容。
4. 支持抓取平台特有的表情在预览中渲染，支持markdown则发送且渲染markdown，支持MFM则MFM，支持发布图片。
5. 支持纯命令行。
6. 不需要抓取该账号关注的帖子/时间线。是否主动抓取该账号最近并非经由本程序发布的帖子有待商量。
7. 支持对一个话题启用追踪，把数个来自不同账号/平台的帖子关联在一起，追踪还没在哪个平台发布，而且可以在发布时基于其他平台修改或者直接原样发送。
8. 支持调用谷歌翻译/DeepL/OpenAI兼容接口翻译内容到多语言。
9. 支持统计数据，如follower number和帖子流量分析。这里可以先不做。
10. webui做简约扁平风格即可，不要卡片，可以有侧边栏。
11. 其他essential功能可以商量。
