# Frontend functional regression checklist

Use this checklist with an isolated data directory and test account. Do not use production data or credentials. Do not trigger the final publish action: inspect the confirmation screen, then return to editing. Record only checks actually completed; a mocked API test is not evidence that a live API or external platform works.

## Run the automated frontend suite

From the repository root:

```sh
npm --prefix frontend test
```

Record the command, date, commit/worktree state, and complete pass/fail summary below. This suite can verify component wiring and mocked HTTP contracts; it does not verify a browser-to-Go connection, persistence across a real restart, or external platform behavior.
